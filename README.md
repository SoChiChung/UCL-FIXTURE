# UCL Fantasy 赛程规划器

一个纯前端的欧冠（UEFA Champions League）Fantasy 赛程规划工具，帮助玩家在赛程结构上做决策。

## 这是什么

基于欧冠联赛阶段赛程数据（开球时间已转换为北京时间 UTC+8），提供一套赛程可视化与组合规划工具：

- **赛程矩阵**：选中球队 × 8 个 Matchday 的赛程矩阵，按比赛日（日期）横向铺开，一眼看清谁先踢、谁后踢、谁撞车。
- **球队选择**：从 36 支参赛球队（按抽签档次 Pot 1~4 分组）中勾选，最多 10 支。
- **比赛日范围筛选**：按 Matchday 起止范围收窄赛程视图。
- **队长路线**：比赛日顺序分析，标注各队开球先后，规划队长切换与撞车风险。
- **赛程推荐**：已选 N 支球队时，推荐最适合作为第 N+1 支的球队（以「填补赛程空缺」为准）。

数据来源：UEFA 欧冠联赛阶段赛程，非官方工具，仅供 Fantasy 参考。

## 技术栈

React 18 + TypeScript + Vite，纯前端静态站，无后端。

## 本地构建

```bash
npm install
npm run build
```

构建产物输出到 `dist/` 目录，可直接部署为静态站点。
